# ADR 0003: Flux pull-based reconciliation

- Status: Accepted
- Date: 2026-08-08

## Decision

Use Flux source-controller and kustomize-controller only. Commit generated,
pinned install manifests. Flux reads the public repository over anonymous HTTPS
with no `secretRef`, PAT, deploy key, SSH key, or write credential. Every tenant
Kustomization uses an explicit least-privilege ServiceAccount. Cross-namespace
references and remote Kustomize bases are disabled.

## Consequences

Protected `main` is production authority. Bootstrap applies controller and sync
manifests once; routine changes are Git-only. Image automation is excluded.
