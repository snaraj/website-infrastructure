# Post-extraction dead-code and stale-surface audit — 2026-08-10

Author: Claude Fable 5. Scope: dead code, stale references, and documentation
drift created by completing the website extraction (main `c104bc8`), found by
a full reachability survey of `scripts/release-gate.sh`,
`scripts/validate_release_transition.py`, `scripts/ci/`, `skills/`, and
`docs/`. Successor to the pre-extraction audit
[2026-08-10-dead-code.md](2026-08-10-dead-code.md), whose D5 planned-dead
inventory the extraction consumed. Corrections for every finding here ride in
the same reviewed PR as this audit at the owner's direction; each finding
names its executable detection.

## PD1 — release-gate.sh was 82.5% unreachable (CONFIRMED, corrected)

1,891 of 2,291 lines (`desired_deployment_image` through the `run_live_gate`
body) were reachable only behind the deliberate fail-closed
`die 'live gate is PENDING its post-cutover successor…'`. Worse, the three
static modes (`--scaffold`, `--release-check`, `--transition-check`) crashed
in `assert_storage_disabled` on greps against deleted
`websites/*/chart/values.yaml` — a confusing storage-violation message whose
real cause was a missing directory (still fail-closed, never fail-open).

Correction: the two embedded Python validators — the only live security value
in the dead span, executed by 25 unit tests — were extracted **verbatim** to
`scripts/validate_flux_release_evidence.py` and
`scripts/validate_runtime_inventory_evidence.py`; the dead shell was removed
(2,291 → 383 lines); the storage assertion now proves the three surviving
platform roots; both runtime lanes keep their exact PENDING dies.
Detection: `tests/security/test_release_gate_contract.py` (27 tests) now
executes the standalone validators, forbids every retired live-machinery name
from reappearing in the shell, and requires both validators to refuse short
argv.

## PD2 — orphaned image-publication lane (CONFIRMED, corrected)

`scripts/ci/publish-oci-artifact.sh`, `publish-stable-oci-tag.sh`, and
`verify-oci-artifact.sh` had zero callers after the publisher workflows moved
to the site repositories — only their own text-pinning tests referenced them.
Publication (and its no-tag-reassignment law) now lives and is tested in each
site repository's tag-triggered publisher. Correction: all three scripts and
their behavior-test files removed; `verify-existing-oci-release.sh` stays as
the live read-only manual verification lane. Detection: repository-wide
reference sweep in CI (`scripts/README.md` linkage test) plus the retrained
media/versioning tests.

## PD3 — Dependabot terraform ecosystem structurally cannot work (CONFIRMED, corrected)

Every scan crashed: the phase roots carry OpenTofu-generated
`.terraform.lock.hcl` files (`registry.opentofu.org` keys), which Dependabot's
terraform updater cannot parse (`T.cast: Expected type String, got type
NilClass` in `update_lockfile_declaration`). A permanently red scheduled scan
normalizes failure. Correction: ecosystem entry removed with the reason
documented in `.github/dependabot.yml`; provider bumps remain reviewed
ceremonies (exact pin + hash lockfiles across seven roots, regenerated by
`tofu init`). Residual risk: provider-currency signal is manual; accepted.

## PD4 — documentation drift to retired lanes (CONFIRMED, corrected)

`docs/runbooks/image-rollback.md` instructed operators to run the retired
`--transition-runtime` Kind rehearsal during a rollback; `public-launch.md`
and `scripts/README.md` described the dead `--live` machinery in present
tense; `AGENTS.md` rules 11/13 and `docs/architecture/overview.md` implied
site source still lives here. All retrained to the split reality. ADRs 0010
and 0014 received dated amendments (never rewrites). Dated audits under
`docs/audits/` were left verbatim as historical records.
