### Fixed

- The edge-probe battery composes its scratch files under a per-test `mkdtemp` directory instead of five fixed `$TMPDIR` paths, so two suite runs sharing a machine no longer overwrite each other's fixtures; a self-scan over the module's own source keeps the fixed-path shape from returning.
- The no-follow path-custody snapshot compares ANCESTOR directories on identity alone — device, inode, mode, owner, group, and the Windows attribute/reparse fields — while the final component keeps its full custody tuple. A sibling process creating or removing an entry in a shared parent changed that parent's link count, size, and timestamps, which the snapshot read as tampering and refused; substitution of any ancestor, a mode change on one, and a rewrite of the target file are each still refused.
- The repository validator scans RoleBinding and ClusterRoleBinding subject blocks with a bounded single-pass line reader instead of a multiline regex whose backtracking grew quadratically: a 40,000-line pathological document took over twenty seconds and now completes in milliseconds, with the budget pinned as a test.
- The Kubernetes deny-fixture runner counts only non-empty `# expect-deny:` declarations and refuses an empty declaration or an empty reviewed sidecar by name, instead of tallying the line and then silently skipping the proof for it.
- The Flux installer's signal-handling battery synchronises on the delayed apply's own log line rather than the first `--dry-run=client` call of the run, so the SIGTERM lands inside the window under test instead of racing an earlier, unsynchronised command substitution.
- `validate_pr_flow.py` accepts every registered agent lane and the `<lane>-<effort>/<issue#>-<topic>` branch grammar, parsing the lane longest-match-first so a hyphenated lane cannot be misattributed to a shorter one that prefixes it.

### Security

- Parser diagnostics in the kubeadm, CNI-manifest, host-prerequisites, and Dependabot validators report structure, counts, and source lines instead of echoing scalars read out of the file under inspection, matching the redaction sink established for the shared parsers.
- Every battery that resolves a host executable at module scope now builds its argv through `support.required_tool`, so a lost or bypassed skip guard fails by naming the missing tool rather than passing `None` — or the literal string `"None"` — into a subprocess or a `Path`. A static analyzer over the battery tree keeps the sweep finished.
- The CRI probe extractors read the bootstrap scripts through one canonicalising helper, so a probe rewritten with escaped dots, double quotes, `$'...'` quoting, or a different spelling of `-Eq` is no longer invisible to the stale-row tripwires; a pattern the shell computes is left exactly as written rather than guessed at.
- The security validator's shell mode words are bound by set equality to the Python check registry, so deleting a check on either side fails loudly instead of leaving an unreachable mode or an unrun check.
- A contract check holds the `github/codeql-action` `init` and `analyze` pins to the same commit SHA and version, and holds the Dependabot group that keeps them moving together.
