### Changed

- Cut the merge-to-live loop for both sites without weakening a control. The promoter's launchd `StartInterval` moves from 900 to 300 seconds, and both sites' `OCIRepository` and `HelmRelease` reconcile at `1m0s` instead of `10m0s`. Every one of those is a read-only poll of already signature-verified state, so the shorter bounds add no credential, no inbound path and no object; a Flux `Receiver` would have added all three and is deliberately excluded. The cadence is pinned where it cannot drift: the constant, the emitted plist and the runbook's one sentence are compared to each other, `scripts/validate_signature_policy.py` states the site chart source's interval as an exact literal, and `scripts/validate_release_state.py` now pins reconciliation cadence PER release identity — one minute for the two sites, ten for the suspended connector — so widening either is a gate failure rather than an edit. Closes #309.
- Make a stalled external call visible while it is stalling. Owner direction 2026-09-04, after one `cosign verify` held the full 600-second command bound and left a single refusal line ten minutes later while the next tick silently retried: every long call — the tick's first fetch and cosign's version check included — now logs `START <kind> <target> budget=<n>s` and `DONE <kind> <target> elapsed=<n>s`, and a failure puts the decision the tick took — `retry`, `refuse` or `skip-this-tick` — on the same line as its redacted reason, because the caller declares that decision once and every call under it reports the truth instead of a guess. Cosign gets its own short budget of 120 seconds with exactly one in-tick retry, so a Sigstore or registry stall costs a couple of minutes and a logged retry rather than a silent ten; both constants are named and pinned like the tick interval. Every tick ends in one `SUMMARY` line — on every exit path, refusals included — naming each workload's verdict and each pull request it touched. `run_command` gains `quiet_output` for a command whose stdout is a credential. The runbook's "Reading the log" lists every shape.
- State the actuals in every promotion pull-request body, so the accounting contract can be satisfied by a cut at all. AGENTS.md requires the commission to state an estimate and the body the actuals; a generated promotion body carried none, which is what refused the 0.1.73 promotion. `Workspace.numstat` measures files, additions and deletions from the index after `add -A` — the same rows for all three, never the length of `apply_promotion`'s returned path list, because a gate that rewrites a tracked file changes what the commit records without changing what the rewrite reported — and refuses a row it cannot measure, a binary path included. One rendered line naming the command that reproduces it reaches the commit message and the body alike, and a body may state it exactly once or the cut refuses. Carries the still-valid diff of PR #308 at 47e1a9ce (superseded) with its two review findings fixed: the live-cut fixture now makes the index and the reported path list disagree in count, so a body counting the tool's own list fails the oracle. Closes #307.
