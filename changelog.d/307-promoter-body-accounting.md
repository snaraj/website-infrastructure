### Fixed

- Give promotion pull requests the actuals AGENTS.md requires of every pull-request body. The commission states an estimate and the body states the actuals, so a material overrun can be seen and the doubling rule applied; `pr_body()` in `scripts/promote_releases.py` emitted a promotion line, an evidence pointer and `Closes #N`, and no accounting at all, which left every cut the tool opens structurally unable to satisfy that rule. The body now carries one line naming the file count, additions, deletions and net, in the shape the agent lanes already write by hand, together with the exact `git diff --numstat <base>..HEAD` command that reproduces it. The numbers are measured from the promoter's own tree rather than derived from the list of rewritten paths, and the same string reaches the commit message and the pull-request body so the two can never disagree. A numstat row that is not two integers and a path — a binary path, which git renders as `-` — refuses the cut instead of stating an accounting the tool cannot prove. Closes #307.
