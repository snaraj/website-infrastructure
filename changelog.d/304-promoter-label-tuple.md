### Fixed

- Make the Ready evaluator's promoter exception exactly one contract tuple wide. AGENTS.md gives the receipted promoter `promoter` in place of the agent pair and fixes its standing label set; `scripts/ready_check.py` demanded `agent-authored` of every author, so no promotion pull request could ever be judged Ready. It now compares the whole set when `promoter` is present — `release`, `security`, `delivery-lane`, `promoter`, `cybersecurity-review-requested` — and blocks an acting-model label, `agent-authored`, a foreign tier, or a missing member alike, which needs no model roster to stay closed. The set is pinned in the evaluator, not read from the tool it judges, and a test reads both and proves they agree. `scripts/promote_releases.py` emits the `security` tier the promotion earns, so the tier and the review label it arms no longer contradict each other. Pull requests without `promoter` are unchanged. Closes #304.
- Stop the inverse-rewrite promoter test from depending on how the committed tree happens to be named. It replays the capture the tree records, so the first promotion this tool cuts onto `main` would leave the scratch tree already carrying the fragment that replay writes, turning the byte-restoration test into `apply_promotion`'s immutable-fragment refusal. The test now builds its fixture in that post-promotion shape and drops that one fragment, exactly as it already drops the forward one, so the removal is load-bearing: delete it and byte restoration errors on the refusal instead of running. `apply_promotion` is unchanged, and the pre-existing `test_refused_fragment_collision_writes_nothing` still pins the refusal on its own.
- Stop the hourly deploy-assurance rewrite from erasing a tracking issue's estimate. `scripts/ci/deploy_assurance.py` regenerated each issue body from the evidence on every tick, so the files/net-lines/review-round estimate AGENTS.md requires of a commission was gone before the pull request answering it stated its actuals. A `## Estimate` block now survives, through one typed parse/render boundary rather than a text guard: `parse_estimate` returns a frozen `Estimate(files, net_lines, review_rounds)` of integers or `None`, and `render_estimate` builds the canonical block back from those integers. The required label set is derived from the dataclass's own fields, the numeric domain is a single bounded ASCII constant, and the sign is required on net lines and refused elsewhere. Nothing from the issue reaches the regenerated body — not an alternative Markdown rendering, not a leading zero, not a Unicode digit — so the class is closed by construction instead of by enumerating spellings. Anything that does not parse preserves nothing, and an unchanged condition stays byte-identical instead of churning.
